## 대중교통

## 자체 단순 약도에 사용할 사실

공식 약도에서 다음 관계를 확인했다. 도로 모양·장식·아이콘·브랜드 로고를 그대로 따라 그리지 않고, 아래 사실만 자체 SVG 도형·텍스트로 표현할 수 있다.

1. 웨딩 시그니처는 **양화로**에 있고, **합정역과 홍대입구역 사이**에 위치한다.
2. 합정역 **2번 출구에서 홍대입구역 방향**으로 양화로를 따라 이동한다.
3. 우리은행이 예식장 가까이 표시되어 있다. **‘옆 건물 우리은행’이라는 하객 안내는 사용자 제공 정보**로 반영하며, ATM의 주말 운영시간·출입 가능 여부는 확인하지 못했다.
4. 약도에는 합정역 2번 출구, 양화로, 웨딩 시그니처, 홍대입구역 방향 정도만 넣어도 기본 동선이 전달된다. 별도의 정문·입구 좌표를 확인하지 않았으므로 정확한 보행 경로나 출입문 위치를 단정하지 않는다.
5. 주차장 세 곳은 별도 텍스트로 안내하고, 실제 주차 진입은 정문 주차요원 안내를 받도록 한다.

권장 표기: **‘위치 관계를 간단히 표시한 약도입니다. 자세한 길찾기는 지도에서 확인해 주세요.’** 자체 약도는 실제 축척이나 북쪽 방향을 보장하는 측량 지도처럼 표시하지 않는다.

## 좌표와 지도 링크

예식장 공식 HTML은 암호화된 파라미터의 네이버 지도 링크를 제공했으며, 숫자 형태의 위도·경도는 확인하지 못했다. 위치 링크는 주소·장소명 검색으로도 충분히 동작하도록 만들 수 있다.

참고 좌표는 **OpenStreetMap의 원본 API**를 조회해 확인했다.

- [원본 장소 노드](https://www.openstreetmap.org/node/9687429517)
- [원본 API XML](https://api.openstreetmap.org/api/0.6/node/9687429517)
- 장소 태그: `name=웨딩시그니처`, `amenity=events_venue`
- 위도: **37.5524991**, 경도: **126.9174283**
- 원본의 마지막 수정·현장 확인일: **2024-09-12**
- 원천·이용 조건: OpenStreetMap contributors, [ODbL 및 표시 안내](https://www.openstreetmap.org/copyright)

이 값은 예식장 업체가 확인해 준 출입구 좌표가 아니다. 건물 장소를 가리키는 참고점으로만 사용하고, 실제 지도상 양화로 87과 동일 장소인지 사용자가 공개 전에 확인한다. 원본 XML은 장소의 도로명 주소 태그를 포함하지 않아 주소로부터 공식 검증한 좌표라고 설명하지 않는다.

카카오 공식 URL 규격에 따른 참고점 링크 예시:

```text
https://map.kakao.com/link/map/웨딩시그니처,37.5524991,126.9174283
https://map.kakao.com/link/to/웨딩시그니처,37.5524991,126.9174283
```

더 보수적인 대안은 확정한 이름·주소를 함께 검색하는 링크이며, 최종 네이버 장소 공유 URL을 사용자 설정에 넣어 교체할 수 있다.

## 확인 방법과 남은 확인

웹 열람 도구로 공식 주소 검색 결과를 확인했으나 공식 페이지 직접 열람은 403/타임아웃을 반환했다. 공개 HTTP 요청으로 `/32`, `/55`, `/35`, `/brandstory`의 현재 HTML을 읽었고, 공식 HTML에 포함된 CDN 안내 이미지 두 장을 직접 시각 열람했다. 인증이나 비공개 계정에 접근하지 않았다. 브라우저 실조작, 현장 방문, 예식장 전화 확인은 하지 않았다.

2027년 7월 3일은 앞으로의 일정이므로 교통 노선·출구 공사·보행 동선·주차장 제휴·주차 조건·은행 ATM 접근 시간이 바뀔 수 있다. 공개 전에 사용자 또는 예식장에 다음 항목을 확인한다.

- 2층 트리니티홀과 예약 일시 일치 여부.
- 입차 기준 2시간 무료 조건과 할인 처리 방법.
- H스퀘어·서교빌딩 제휴 주차장 사용 여부 및 당일 안내.
- 식장 내 ATM 부재와 옆 우리은행 ATM 주말 출입 가능 시간.
- 최종 지도 링크가 양화로 87의 올바른 장소를 여는지 여부.
