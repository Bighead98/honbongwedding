# 디자인 참고 자료와 확인 범위

확인일: **2026-10-04, Asia/Seoul**. 초기 조사는 업체가 공개한 상품 상세, 공식 미리보기, 공식 샘플 이미지를 참고했다. 이후 사용자가 직접 제공한 참고 링크는 아래 별도 항목에서 구조·여백·색상만 확인했다. 개인 청첩장의 사진·이름·연락처·계좌 등 개인정보는 수집·저장·재사용하지 않았다. 업체 사진·문구·장식·코드는 이 프로젝트에 복제하지 않았다.

## 확인 방법과 한계

- 웹 검색 및 실제 URL 열람으로 공식 샘플 제공 여부와 공개 HTML에 포함된 구성 정보를 확인했다.
- 바른손 공식 미리보기 3개의 표지 좌표·크기·타이포그래피·섹션 목록을 읽었다.
- 봄카드와 투아워게스트의 공식 샘플 이미지를 내려받아 시각적으로 열람했다. 이미지는 임시 작업 폴더에서만 확인했고 사이트 자산으로 사용하지 않았다.
- 브라우저 스킬을 사용해 연결을 시도했으나 `No browser is available`, 브라우저 목록 `[]`를 반환했다. 따라서 **샘플 페이지를 브라우저에서 렌더링하거나 실제로 스크롤·갤러리·계좌·음악·공유 버튼을 조작한 검증은 하지 않았다**.
- 미리보기의 구성 데이터는 실제 렌더링 결과와 다를 수 있다. 확인하지 못한 기능을 동작한다고 주장하지 않는다.

### 구조와 시각 설정에서 확인한 내용

| 항목 | 확인한 설정·구조 | 우리 초안에 적용할 일반 원리 |
| --- | --- | --- |
| 본문 폭 | 중앙정렬, `max-w-md`, 데스크톱에서 400px 폭 클래스 | 긴 단일 페이지를 모바일 폭으로 유지 |
| 여백 | 좌우 패딩 및 구역별 상하 패딩·간격 클래스가 분리됨 | 표지와 각 구역에 독립적인 여백 제공 |
| 색상 | 밝은 `#F8F8F8` 바탕과 `#333`, `#494949` 텍스트 값 | 아이보리와 짙은 본문의 충분한 대비 유지 |
| 활성 구역 순서 | 초대글 → 달력 → 혼주 → 갤러리 → 오시는 길 → 마음 전하실 곳 → 참석 의사 → reception 설정 | 예식 날짜·달력을 갤러리보다 먼저 배치 |
| 달력 | 달력 사용, 카운트다운 사용, D-day 문구 미사용 | 날짜 정보는 사진 앞에서 쉽게 확인 |
| 갤러리 | 3열 그리드, 확대 뷰어 사용, 슬라이더 사용, 버튼형 이동 설정 | 사진은 썸네일과 확대 화면을 함께 제공 |
| 계좌 | `accordion`과 계좌 숨김 설정 값 확인 | 신랑·신부 측을 접고 펼쳐 문서 길이 줄이기 |

구역 설정에는 비활성 구역도 함께 들어 있어, 활성 값이 참인 구역만 위 순서에 포함했다. reception 설정이 실제 화면에서 어떤 문구나 행사로 표시되는지는 개인정보를 확인하지 않고 남겨두었다. 당사자의 구체적인 행사 구성이나 개인 데이터를 우리 청첩장에 옮기지 않는다.
