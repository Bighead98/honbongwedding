# 도메인 선택과 비용 조사

확인 날짜: **2026-10-04, Asia/Seoul**. 아래는 공식 페이지에서 확인한 내용이다. 실제 구매, 결제, 장바구니 신청, DNS 변경은 하지 않았다. 가격은 결제 시점에 다시 확인해야 한다.

## 공식 검색·구매 링크와 추천

| 업체 | 공식 도메인 검색·구매 | 관리 편의성 판단 |
| --- | --- | --- |
| 가비아 | [가비아 도메인 검색](https://domain.gabia.com/) | 국문 검색·연장·네임서버/DNS 관리 메뉴와 국문 고객센터가 한곳에 있어 처음 직접 운영할 때 추천한다. |
| 호스팅케이알 | [HostingKR 도메인 검색](https://www.hosting.kr/domain/search) | 국문 검색·관리 콘솔과 전화·채팅·온라인 문의를 제공한다. 가격과 VAT를 결제 화면에서 함께 비교한다. |
| 후이즈 | [후이즈 도메인 검색·등록](https://domain.whois.co.kr/regist/dom.php) | 국문 검색·연장·등록정보/네임서버 변경 메뉴를 제공한다. 비용 안내 페이지는 이번 열람에서 오류가 나 상세 가격은 확인하지 못했다. |

**추천은 가비아다.** 최저가라는 판단이 아니라, 국문 안내와 관리 메뉴, 신규 할인과 향후 정가를 공식 문서에서 함께 확인할 수 있다는 점을 고려한 선택이다. 도메인만 등록하고 실제 웹사이트는 Cloudflare Pages에 두면 된다. 유료 웹호스팅 상품을 함께 구매할 필요는 없다. 관리 메뉴와 지원은 각 [가비아 공식 도메인 페이지](https://domain.gabia.com/), [HostingKR 공식 검색 페이지](https://www.hosting.kr/domain/search), [후이즈 공식 등록 페이지](https://domain.whois.co.kr/regist/dom.php)에서 확인했다.

## 확인한 가격과 확인하지 못한 조건

비교 기준은 일반적인 **영문 .com, 1년**이다. 프리미엄 도메인, 부가서비스, 장기등록은 별도 조건일 수 있다.

| 업체 | 신규 등록 | 갱신/연장 | 부가세 | 프로모션·제한 |
| --- | --- | --- | --- | --- |
| 가비아 | 초년도 이벤트 **19,800원**. 현재 정가 **24,000원**, VAT 별도 | 2026-10-04 기준 정가 **24,000원**, VAT 별도 → **26,400원** | 이벤트 19,800원은 **VAT 포함**. 정가 24,000원은 **VAT 별도** | .com 신규 신청 고객의 초년도 할인. 결제 완료 필요. 2년 이상 등록은 다른 할인율. 이벤트 종료일은 열람한 페이지에 표시되지 않음. |
| HostingKR | 검색 첫 화면에 **18,000원/년** 표시, 비교 가격 **23,000원/년** 표시 | 페이지에 신규등록·기간연장·기관이전 동일 가격이라는 일반 안내는 있음. **18,000원의 갱신 적용 여부·상세 조건은 확인 필요** | 현재 18,000원 표시의 VAT 포함/별도는 이번 페이지에서 **확인하지 못함** | 상세 TLD 가격 표가 로딩 상태라 할인 기간·대상·갱신 범위를 확인하지 못함. 과거 공지 가격을 현재 가격으로 사용하지 않음. |
| 후이즈 | **확인 필요** | **확인 필요** | **확인 필요** | 공식 등록비용 안내 링크가 열람 도구에서 서버 오류를 반환. 이벤트 배너만으로 등록·갱신 가격을 추정하지 않음. |

가비아의 이벤트 가격·조건은 [인기 도메인 프로모션](https://event.gabia.com/domain/famous/)에서 확인했다. 정가·연장 적용 범위와 VAT는 [2026-10-01 가격 인상 공지](https://www.gabia.com/gabia_notice/view.php?seq_no=45623)에서 확인했다. 공지에 따르면 **2026-11-01부터 .com 신규·연장·기관이전 정가는 25,000원/VAT 별도(27,500원/VAT 포함)**로 바뀐다. 이는 앞으로 적용되는 정가이며, 내년 갱신비를 보장하는 가격은 아니다. 현재 이벤트가 이후에도 유지된다고 가정하지 않는다.

HostingKR 표시 가격과 동일 가격 일반 안내의 근거는 [공식 검색 페이지](https://www.hosting.kr/domain/search)다. 후이즈의 확인 실패한 공식 비용 링크는 [도메인 등록비용 안내](https://cs.whois.co.kr/faq/?p=list&number=3)다. 모든 업체에서 구매 직전 **첫해 총액 / 이후 연장 총액 / VAT / 자동연장 / 선택 부가서비스**를 확인한다.

## 이름 기반 도메인 후보

이호정·박소정의 **영문 표기는 아직 미확정**이다. 아래에서는 임시로 `hojeong`, `sojeong`을 사용했으며, 여권 표기나 두 사람이 선호하는 표기에 맞춰 바꿀 수 있다. 도메인 검색으로 실제 등록 가능 여부를 확인하지 않았다.

| 후보 | 제안 이유 | 등록 가능 여부 |
| --- | --- | --- |
| `hojeong-sojeong.com` | 두 사람 이름을 읽기 쉽게 연결 | **확인 필요** |
| `hojeongandsojeong.com` | 두 이름을 함께 담는 표기 | **확인 필요** |
| `hj-sj-wedding.com` | 이름 이니셜과 용도를 함께 표시 | **확인 필요** |
| `hojeong-sojeong.kr` | 한국 하객에게 익숙한 .kr 주소 | **확인 필요** |

위 후보는 구매한 주소가 아니며, 프로젝트의 최종 대표 주소도 아니다. 예식 날짜가 확정되기 전에는 날짜를 도메인에 넣지 않는 편을 권한다. `.wedding` 등 다른 확장자는 첫해 할인보다 **갱신 가격**을 먼저 비교한다.

## 구매 이후 비용과 운영

Cloudflare Pages의 정적 파일 호스팅 무료 범위와 도메인 등록비는 서로 다른 비용이다. 도메인에는 연 단위 연장 비용이 계속 발생한다. 부가서비스·유료 Cloudflare 기능은 선택하면 별도 과금될 수 있으므로 이 프로젝트에서는 필요할 때만 검토한다. Pages 정적 파일 요청은 무료이며 Functions를 호출하면 다른 과금 규칙을 적용한다. [Cloudflare 공식 과금 안내](https://developers.cloudflare.com/pages/functions/pricing/)

도메인 등록 계정과 소유자 이메일은 두 사람이 직접 관리한다. 만료일을 달력에 기록하고 자동연장 설정과 연락 이메일을 확인한다. 비밀번호·OTP·카드번호를 개발자에게 전달할 필요는 없다. 예식 후 운영 기간이 끝나면 사이트를 먼저 정리한 뒤, 도메인을 계속 소유할지와 자동연장을 중단할지를 결정한다. 사이트 배포와 종료 순서는 [DEPLOYMENT.md](./DEPLOYMENT.md)를 따른다.
