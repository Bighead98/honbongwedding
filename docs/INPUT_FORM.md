# 남은 정보 입력 양식

예식 날짜·시각·장소·가족 표기와 공개일부터 1년 유지 희망을 반영했습니다. 사용자 폴더의 실제 웨딩사진 10장과 제공한 계좌 5개(신랑 측 2개·신부 측 3개)도 적용했습니다. 연락처는 사용하지 않으며 전화·문자 버튼을 표시하지 않습니다. 이미 전달한 사진이나 계좌를 다시 보내실 필요는 없습니다.

현재 신랑·신부 이름과 멘트는 나눔손글씨 펜, 부모님 성함·‘의 아들/딸’과 날짜·교통·계좌·버튼은 SUIT로 표시합니다. 글꼴은 두 종류이며 읽기 쉽도록 키운 크기와 명암을 유지합니다. 초대 글은 일상의 작은 다정함을 담은 8행 문구입니다. ‘화환은 정중히 사양합니다.’는 초대 화면의 가족 소개 아래에 큰 별도 안내로 표시합니다.

이주은 성함 옆 국화꽃과 스크롤 등장 효과도 유지합니다. 로컬 미리보기는 효과를 기본으로 켜고, 운영 주소는 시스템의 동작 줄이기 설정을 따릅니다. 상단 효과 전환 버튼은 제거했으며 Windows 설정은 변경하지 않습니다. 약도는 합정역이 오른쪽, 홍대입구 방향과 우리은행이 식장 왼쪽입니다. 제작용 설명은 화면에서 제거했습니다.

아래 항목은 바꾸거나 추가하고 싶을 때만 작성합니다.

```text
가족 표기 최종 수정 사항(없으면 현재 표기 사용):
  신랑: 이창균 · 이주은(국화꽃)의 아들 이호정
  신부: 박길순 · 조진희의 딸 박소정

초대 문구 추가 수정 사항(없으면 현재 8행 문구 사용):
음악 추가 수정: 일반 A_song.mp3 / BACKROOM B_song.mp3 (이미 적용) / 웹 게시 이용 권한
영문 이름 표기:
선호 도메인 후보:
공개 시작 희망일:
유지 기간: 공개일부터 1년(이미 요청)
```

일반 화면에 `A_song.mp3`, BACKROOM에 `B_song.mp3`를 적용했습니다. 하단에서 코드 `honbong98`을 입력하면 강렬한 별도 화면과 사용자 제공 일상 사진 10장·자동 반복 포토부스 영상을 볼 수 있습니다. 외부 공개 전에는 가족·계좌의 공개 동의와 사진·음원의 웹 게시 권한을 확인합니다. 현재는 로컬 검토본이며 공개 주소·카카오 JavaScript 키는 미설정입니다. 비밀번호·OTP·카드번호·은행 로그인 정보·배포 토큰은 이 양식에 적지 않습니다.

사진 처리 내역과 원본 보관 위치는 [자산 출처](ASSET_SOURCES.md), 이후 수정 방법은 [README](../README.md)에 있습니다. 예식 전에는 주차 제휴·무료 조건, 옆 우리은행 ATM의 주말 출입 시간, 지도 링크의 실제 목적지를 확인하면 됩니다. 교통·시설 안내는 이후 바뀔 수 있습니다.
